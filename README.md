###  Projetos em destaque

#### 🐳 [devops-portfolio-api](https://github.com/ricardolagarini/devops-portfolio-api)
API REST em **FastAPI**, containerizada, com **pipeline CI/CD completo** (lint, testes, build Docker multi-stage, scan de segurança com Trivy), publicação de imagem no **GHCR** e **infraestrutura como código em Terraform**. O objetivo do projeto não é a lógica de negócio — é tudo o que a rodeia: como é construída, testada, analisada, publicada e operada.

`Python` · `FastAPI` · `Docker` · `GitHub Actions` · `Terraform` · `Trivy` · `PostgreSQL`

#### ⚔️ [new-rpg](https://github.com/ricardolagarini/new-rpg)
RPG por turnos em **Java**, jogado no terminal: classes de herói (Cavaleiro, Arqueiro, Feiticeiro), sistema de loja, batalhas por turnos, áudio e leitura de dados via CSV. Projeto académico do CESAE aplicando **Programação Orientada a Objetos** e o padrão **Strategy**.

`Java` · `OOP` · `Strategy Pattern` · `CSV` · `javax.sound`
